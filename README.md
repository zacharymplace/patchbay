# Patchbay

Patchbay is a systems puzzle game about building calm judgment into noisy environments.

Core promise:

> Route the signal. Tune the system. Don't let the board lie to you.

## Current Status

Doctrine/build planning only.

No engine code has been written yet.

## Build Rule

Engine first. UI second.

The simulation must work from the terminal before the browser UI is polished.
